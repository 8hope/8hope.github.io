Personal rclone backup

This is a private, single-user Google OAuth client for rclone, the open-source command-line tool for syncing files to cloud storage. It is used by one person to back up their own files from their own computer to their own Google Drive.

The backup runs on a schedule on that computer. Files are encrypted on the computer with rclone's crypt feature before they are uploaded, so Google Drive only ever holds encrypted copies. The app is not offered to anyone else and there is no server, website login or account to sign up for.

Access requested from Google:

  • drive.file: create and manage the backup files that this app itself uploads.
  • drive: used only by the owner, from the command line, to place and check files in their own Drive.
